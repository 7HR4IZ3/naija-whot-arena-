# Whot Arena classic deck

Original SVG artwork generated by `scripts/generate-cards.mjs`. There are 50 distinct faces, including the Whot 20 face used five times in the standard 54-card deck, and one reversible back.

Visual reference: the photograph captioned “Whot cards (Nigerian version)” on https://en.wikipedia.org/wiki/Whot! . The card proportions, burgundy ink, mirrored number/suit indices and central star score inform the design. No photograph or traced publisher artwork is embedded. The Whot wordmark is a typographic interpretation, not an official publisher logo.

Each SVG is standalone and can be used at any resolution. Run `node scripts/generate-cards.mjs` to regenerate.
